حفظني الكلمات — إعادة التصميم

المحتويات:
- index.html: الموقع كامل (HTML + CSS + JavaScript).
- manifest.webmanifest و sw.js: دعم التثبيت كتطبيق PWA.
- icon.svg: أيقونة الموقع.

التشغيل:
1) فك ضغط الملف.
2) افتح المجلد باستخدام VS Code.
3) شغّل index.html عبر Live Server، أو ارفع المجلد على Vercel / Netlify.
4) التثبيت كتطبيق يحتاج HTTPS أو localhost.

التصميم الجديد:
- واجهة أبيض وأسود.
- خلفية بعناصر كتب وأدوات تعليمية متحركة.
- قائمة جانبية كبيرة بعرض يقارب ربع الشاشة على الكمبيوتر، وتناسب الموبايل.
- تبديل واجهة عربي / English من داخل القائمة.
- تم الاحتفاظ بوظائف الكلمات والتدريب والتكرار والمراجعة والتصدير والاستيراد.

ملاحظة: الترجمة الآلية للكلمات تعتمد على خدمة ترجمة خارجية كما في النسخة الأصلية، وقد تتأثر بتوفر الخدمة والإنترنت.
