حفظني الكلمات — Save My Words

الملفات:
- index.html : الموقع كامل (HTML + CSS + JavaScript) بدون أي مكتبات خارجية.
- manifest.webmanifest + sw.js + icon.svg + icon-192.png + icon-512.png : دعم التثبيت كتطبيق (PWA).

التشغيل:
1) فك الضغط.
2) للتجربة: افتح index.html أو شغّله بـ Live Server في VS Code.
3) للنشر: ارفع المجلد كما هو على Vercel أو Netlify (لا يحتاج Build).
4) التثبيت كتطبيق يحتاج HTTPS (يتوفر تلقائيًا على Vercel / Netlify) أو localhost.

ملاحظات:
- الترجمة التلقائية تعتمد على خدمة MyMemory المجانية وتحتاج إنترنت.
- الأصوات تختلف حسب الجهاز والمتصفح. لصوت أنثوي ثابت على كل الأجهزة يلزم خدمة صوت خارجية.
- البيانات محفوظة محليًا في المتصفح (localStorage). استخدم تصدير النسخة الاحتياطية من الإعدادات لنقلها لجهاز آخر.
- النسخة الجديدة تستخدم مفاتيح تخزين مختلفة عن النسخة القديمة، فكلمات النسخة القديمة لا تنتقل تلقائيًا.
