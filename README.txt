حفظني الكلمات — Save My Words (نسخة مصححة)

محتويات المجلد:
- index.html: واجهة الموقع والكود الأساسي.
- manifest.webmanifest: إعدادات تثبيت التطبيق (PWA).
- sw.js: التخزين المؤقت ودعم العمل دون اتصال.
- icon.svg: أيقونة المتصفح بصيغة SVG.
- icon-192.png و icon-512.png: أيقونات التطبيق بمقاسي 192 و512.

التشغيل:
1) فك ضغط ملف ZIP كاملًا.
2) للتجربة المحلية: شغّل المجلد عبر VS Code Live Server أو خادم محلي.
3) للنشر: ارفع محتويات المجلد كما هي إلى Vercel أو Netlify.
4) تثبيت PWA يحتاج HTTPS أو localhost. لا ترفع index.html وحده إذا أردت التثبيت والأيقونات والعمل دون اتصال.

استيراد الكلمات:
1) صوّر الكلمات ومعانيها بوضوح.
2) من صفحة Excel اضغط «نسخ طلب الـ AI».
3) الصق الطلب في أداة ذكاء اصطناعي وأرفق الصور.
4) نزّل ملف XLSX الذي ينشئه الذكاء الاصطناعي.
5) ارجع للموقع وارفع ملف Excel.

طلب الذكاء الاصطناعي يتغير حسب اللغة المختارة في الموقع. المطلوب ملف XLSX بعمود عربي وعمود باللغة المختارة، مع صف مستقل لكل كلمة.

ملاحظات:
- استيراد XLSX/XLS يعتمد على تحميل SheetJS من الإنترنت عند أول استخدام.
- الترجمة التلقائية تعتمد على خدمة MyMemory وتحتاج اتصالًا بالإنترنت.
- البيانات محفوظة محليًا في المتصفح (localStorage). استخدم التصدير من الإعدادات لعمل نسخة احتياطية.
